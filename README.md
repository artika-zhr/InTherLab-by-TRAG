# InTherLab — Interactive Thermodynamics Laboratory

InTherLab is an interactive virtual thermodynamics laboratory
developed by TRAG, Physics Education Study Program,
Universitas Negeri Medan.

## About

InTherLab is designed to support thermodynamics learning through:

- Interactive simulations
- Visualizations
- Graphs
- Virtual experiments
- Data analysis
- Calculations
- Quizzes
- Real-life applications

## Learning Flow

Phenomenon → Prediction → Simulation → Data → Graph → Explanation → Application → Quiz

## Main Modules

1. Fondasi Termodinamika
2. Usaha & Proses Termodinamika
3. Hukum I Termodinamika
4. Gas Ideal & Kapasitas Kalor
5. Hukum II Termodinamika & Entropi
6. Mesin Kalor & Mesin Carnot
7. Mesin Pendingin
8. Hukum III Termodinamika & Pengayaan
